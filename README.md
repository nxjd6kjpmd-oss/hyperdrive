# Hyperdrive

A Sega Genesis / Mega Drive emulator that runs in the browser, built for phones (portrait and landscape) with touch controls, Xbox controller support, save states, rewind, fast-forward, CRT/scanline filters, region switching and Sonic & Knuckles lock-on.

No ROMs are included. You add your own; they stay in your browser's storage on your device.

## Install on iPhone
Open the GitHub Pages URL in Safari → Share → **Add to Home Screen**.
